# Simple Portfolio

A clean, responsive portfolio landing page built with HTML and CSS. It showcases a personal profile, contact links, and several project cards with colorful sections and modern styling.

## Overview

This project is a simple one-page portfolio designed to present:

- a short personal introduction
- profile image and contact icons
- project highlights with visual cards
- a polished responsive layout for smaller screens

## Tech Stack

- HTML5
- CSS3
- Static assets for images/icons

## How to Run

1. Open the project folder.
2. Double-click `index.html` in a browser, or use a local development preview extension.
3. The page should load with the portfolio layout and styling applied.

## Customization

You can easily update:

- the name and intro text in `index.html`
- social links in the contact section
- project names and descriptions
- the color scheme and layout spacing in `style.css`
- the profile and project images in the `media/` folder
